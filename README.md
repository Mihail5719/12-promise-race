# 🏁 Promise Race — собственная реализация

Веб-приложение, демонстрирующее собственную реализацию комбинатора `Promise.race()`:
функция принимает массив промисов и возвращает первый завершившийся —
исполнившийся **или** отклонённый.

## 🎯 Назначение проекта

Домашнее задание по теме «Современный Асинхронный JavaScript»
(курс JavaScript Advanced, PurpleSchool).

**Условие:** создать функцию `race()`, которая принимает массив Promise
и возвращает первый успешно выполненный или отклонённый.

Вместо вызова нативного комбинатора проект реализует его с нуля
и в реальном времени сверяет результат с `Promise.race`.

## ✨ Основные возможности

- 🧩 **Собственная `race()`** — на `new Promise` с пробросом внешних `resolve`/`reject` каждому участнику
- 🏃 **Демо-стенд**: три «сервера» со случайными задержками 300–2000 мс, у каждого 25% шанс «упасть»
- 🏆 **Два исхода гонки**: зелёный блок при fulfilled-победителе, красный при rejected-победителе
- 📜 **Журнал гонки**: все финиши участников с временем в миллисекундах
- ✅ **Сверка с нативным `Promise.race`**: обе реализации стартуют на одних участниках, результаты сравниваются через `Promise.allSettled`
- 🧪 **Самотесты в консоли**: три сценария при загрузке страницы (первый fulfilled, первый rejected, не-промис)

## 🧠 Как устроена race()

```js
function race(promises) {
  return new Promise((resolve, reject) => {
    for (const item of promises) {
      Promise.resolve(item).then(resolve, reject);
    }
  });
}
```

1. Создаётся результирующий промис
2. На каждого участника подписываемся, передавая обработчиками внешние `resolve`/`reject`
3. Первый завершившийся участник единолично settle-ит внешний промис
4. Повторные вызовы игнорируются: промис завершается только один раз (идемпотентность)
5. `Promise.resolve(item)` оборачивает не-промисы — они побеждают мгновенно, как в нативной версии

## 📊 Контекст: комбинаторы Promise

| Метод | Ждёт | Результат |
|-------|------|-----------|
| `Promise.all` | всех fulfilled или первого reject | массив значений / первую ошибку |
| `Promise.allSettled` | завершения всех любым исходом | отчёт `{status, value/reason}` по каждому |
| **`Promise.race` / наша `race()`** | **первого завершившегося** | **его значение или ошибку** |
| `Promise.any` | первого fulfilled | значение; ошибку, только если упали все |
